# 受限 QMT 最小只读桥接

## 目标与执行边界

在已限制文件读取的国金 QMT 模拟端，验证外部 Python 经本机 ZMQ 请求 QMT，并取得真实持仓和一只股票行情。仅交付本地代码、模拟端运行与结果核对，不包含实盘、下单、撤单、订阅、下载、Gateway 配置修改或生产发布。

现有入口通过 `open()` 加载模块，在模拟端触发 `Foribdden FileIO`。已有完整单文件打包器会重置共享模块并加载交易运行时，本次使用独立只读入口，保留原策略。

## 最小链路

外部 Python 的现有 `bigqmt_no_redis.ZmqTransport` DEALER → QMT 内置 Python 的同一传输实现 ROUTER → QMT 定时回调 → 原生查询 → 既有持仓转换和 JSON 序列化 → 外部 Python。

- 自定义模块在构建时内嵌；运行时不读取源码、配置或日志文件，不修改全局 `importlib` 或 `sys.modules`。
- 生成文件使用 ASCII 外壳、UTF-8 源码的 base64 内嵌，避免 QMT 编辑器按 GBK 保存时与源码编码声明冲突。
- 支持 `ping`、`get_positions`、`get_full_tick`（兼容既有名称 `get_ticks`）。其他方法在接触 QMT 前拒绝。
- 请求账户及参数账户须与固定模拟账户一致；过期请求拒绝执行。
- 持仓复用 `BigQmtPositionProvider.get_positions_with_evidence`；不完整转换返回失败，保留证据状态，不能把查询失败当作空仓。
- 本次原生样本中 18 行的 `m_dMarketValue` 为 `inf`，而既有同义字段 `m_dInstrumentValue` 有有限数值。仅在严格证据转换的市值字段中选择首个有限候选；所有候选无效时仍失败，主字段为零时保留零，不以价格乘数量估算。
- 每个行情请求最多一只合法SH/SZ/BJ证券，按请求中的代码读取；初始配置代码仅为启动元数据，不作为证券准入名单。返回原生快照时间，盘后快照不计实时行情验收。
- QMT 查询仅在其定时回调内执行；传输不开启接收后台线程。
- 绑定 `127.0.0.1` 的独立端口；达到有限请求数或时限后释放本次端点，避免残留测试服务。

## 交付与验收

1. 入口、最小单文件构建器、针对性测试和本文档。
2. 模拟端编译运行；外部客户端依次核对 ping、带来源证据的持仓、`000001.SZ` 行情。
3. 无效方法及错误账户请求被拒绝；QMT 日志与外部响应的请求标识一致。
4. 停止并清理本轮模型、临时端点；保留源码、结果和可恢复备份。原有策略、账户绑定及生产服务保留。

运行方式：`conda run --no-capture-output -n alex_quant_platform_dev python tools/build_readonly_single_file.py --output <临时产物路径>`。生成文件的账户仍为占位符，模拟部署时只在临时副本中替换为已确认的模拟账户。

## 单模型三个运行体的共存构建

另一组历史候选是`tools/build_p1_coexist_single_file.py`、`tests/test_p1_coexist_runtime.py`及`tools/build_single_file.py`的隔离加载选项。用途是在同一个QMT模型中保留原Redis协议，同时运行独立的只读SHM和执行SHM通道；不表示两个图表模型可并行，也不表示已验收实盘交易。

- 构建仅接受固定模拟STOCK账户及离线字面配置快照，显式核对原生PID、Windows会话、不同的SHM名称、请求上限和绝对停止时间；三个通道均禁用下单、撤单，Redis应用自动交易tick也关闭。
- 初始行情代码只作启动元数据，格式、去重和数量校验保留，集合外合法代码可由读取通道查询。`--symbols`帮助及对应测试已按此口径更新。
- 原Redis单文件构建器新增`isolated=True`时必须显式提供配置，使用候选自己的模块表和导入视图，不改全局`importlib`、不替换共享模块、不停止其他候选；默认构建方式保留原行为。
- 只绑定本候选的原生函数、资源和回调，禁用上下文后台预热及全局GIL调整。初始化失败、超时、请求预算耗尽时释放本候选资源；共享连接池只断开一次，其他运行体的连接不受影响。
- 候选可能含连接配置，输出通过独占创建且创建时请求`0600`权限，拒绝覆盖已有文件。本轮在Mac验证创建时权限及原文件内容保护；不将该权限位检查等同于Windows ACL验收。离线配置快照和生成产物不纳入提交。

构建入口：

```text

  --config-snapshot <离线字面配置.py> --output <新的候选文件.py>
```
